Настоящий ИИ (Gemini)

Подключите — и Джарвис ответит на любой вопрос, решит задание по фото (любой предмет) и разберёт скриншот графика. Бесплатно, банковская карта не нужна.

Как получить ключ (2 минуты):
1. В Safari откройте aistudio.google.com/apikey и войдите в Google-аккаунт.
2. Нажмите Create API key и скопируйте ключ.
3. Вставьте его ниже.
Ключ хранится только в памяти этого телефона и отправляется только в Google. Никому его не показывайте и не вставляйте в файлы на GitHub, иначе им смогут пользоваться чужие люди. На бесплатном тарифе действуют лимиты, а Google может использовать отправленные данные для улучшения своих продуктов — не отправляйте личные документы. ИИ может ошибаться.

Свой сервер (для продвинутых)

По умолчанию приложение ничего не отправляет в интернет. Если у вас есть собственный сервис (HTTPS), его можно подключить для свободных вопросов и разбора скриншотов. Секретные ключи в приложении не хранятся: ключ должен лежать на вашем сервере. Перед первой отправкой приложение покажет адрес и попросит подтверждение. Формат запросов описан в README.

О проекте

JARVIS — локальный ассистент (команды, математический решатель, анализ свечей, калькулятор риска; всё считается на телефоне и ничего не отправляется) плюс необязательный настоящий ИИ. Если вы вставите свой бесплатный ключ Gemini, то вопросы, фото заданий и скриншоты графиков отправляются в Google для ответа — только после вашего подтверждения. Без ключа из приложения ничего не уходит (кроме загрузки OCR-модуля по вашему согласию). Раздел «Трейдинг» — образовательный, не инвестиционная рекомендация.
